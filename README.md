# Mi-control-nutricional

## Compartir e instalar

Publica la app en una URL HTTPS y comparte esa misma dirección. En Android, ábrela
en Chrome o Samsung Internet y selecciona **Añadir a pantalla de inicio** o
**Instalar app** en el menú del navegador. En iPhone, usa **Compartir → Añadir a
pantalla de inicio** en Safari.

La estructura de la página puede abrirse sin conexión después de haberla cargado,
pero los estilos externos y los análisis de IA requieren internet. Los análisis
también necesitan una clave API de Google. El perfil, la clave y los registros se
guardan en el navegador de cada dispositivo; no se sincronizan entre móviles.
